## Project Description
The **Student Portal** is a web-based application designed for students to easily access their academic information. Features include login authentication, dashboard navigation, course and grade viewing, interactive charts, and a responsive, modern UI with **light and dark modes**.

---
## Features Included
- **Login/Register Page**
  - Secure login system with username and password.
  - Error handling for invalid credentials.
  - Dark mode toggle for user preference.
  - Particle background animation for enhanced UI.

- **Dashboard**
  - Personalized welcome message.
  - Shortcut cards linking to important platforms (Library, UFUTURE, Mission & Vision).
  - Summary cards for Courses Enrolled, Completed Assignments, Average Grade, and Attendance.
  - Interactive bar charts for Grades Overview and Attendance Overview.
  - Dark mode support for both desktop and mobile.

- **Courses Page**
  - List of courses enrolled by the student.
  - Course details including code, name, lecturer, and schedule.
  - Responsive layout for desktop and mobile.
  
- **Grades Page**
  - Overview of grades per course.
  - Interactive charts to visualize grade distribution.
  - Summary of average grades.
  - Dark mode support.

- **Assignments Page**
  - List of assignments 
  - Status tracking (completed)

- **Attendance Page**
  - Attendance records per course.
  - Bar chart visualization for better insight.
  - Summary of overall attendance percentage.

- **Profile Page**
  - Display student personal details (name, matric number, semester).
  - Shows profile picture (with hover animation effect).
  - Shows Program name and CGPA.
  - Features a Digital Student Card that can be viewed and downloaded.

- **Navigation Bar (Desktop & Mobile)**
   - Horizontal top navbar for desktop and mobile screens.  
   - Hamburger menu for mobile; expands/collapses the menu.  
   - Active page link is highlighted.  
   - Includes **Logout** link.  
   - Dark mode toggle available on both desktop and mobile. 
    
- **Footer**
  - Quick links to UiTM resources.
  - Contact information and social media links.
  - Support links including FAQ, Privacy Policy, Terms & Conditions.
  - **Consistent Footer**: Appears across all pages.
  
- **General**
  - Fully responsive for desktop and mobile devices.
  - Dark mode toggle available on all pages.
  - Consistent UI/UX across pages.
  - Smooth animations and hover effects.
  - Logout functionality.
  - Interactive Charts: Hover or touch to display data dynamically.  

- **Animated UI Elements**:
  - Particle.js animated background  
  - Marquee reminder bar  
  - Ripple button effect

## Frameworks / Libraries Used
- [Tailwind CSS](https://tailwindcss.com/) – For styling and responsive design.
- [Font Awesome](https://fontawesome.com/) – For icons.
- [Chart.js](https://www.chartjs.org/) – For interactive charts.
- [Particles.js](https://vincentgarreau.com/particles.js/) – For particle animations on login page.
- Google Fonts – For typography (`Inter` and `Lora` fonts).
- **Vanilla JavaScript** – Login validation, dark mode toggle, UI interactions.
